# NT Driver - demo

Demo interativa do **NT Driver**, app de controle financeiro para motoristas de aplicativo (Uber, 99, InDriver).

**Ver a demo:** https://nathansouza-hub.github.io/nt-driver-demo/

A página roda inteira no navegador, com dados de exemplo, e reproduz a lógica de cálculo do app real: dashboard do mês, registro diário, metas diárias com folgas e contas a pagar.

Stack do app: React 18, React Router, Vite, Node.js, Express, PostgreSQL, Render, Supabase, Resend.
